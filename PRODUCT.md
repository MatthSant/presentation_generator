# Product

## Register

product

## Users

Consultores de dados que revisam análises de LTV e conversão antes de apresentar ao cliente. Contexto de uso: pré-reunião, foco em leitura rápida de achados, anotação de insights e validação de narrativa.

## Product Purpose

App interno de relatórios analíticos — transforma JSONs gerados por Python em relatórios navegáveis com gráficos, seções, filtros e sistema de comentários. Substitui o PowerPoint para análises exploratórias de dados de clientes.

## Brand Personality

Analítico, preciso, discreto. "Consulting report que virou app."

## Anti-references

- BI genérico (Tableau, PowerBI): denso, corporativo, datado
- SaaS americano clichê (Metabase, Mixpanel): navy azul, cards idênticos, dashboard 3.0
- Glassmorphism decorativo: blur e gradiente sem substância
- Hero-metrics com número gigante e gradiente

## Design Principles

1. **Data quiet**: a interface serve os dados, nunca compete com eles. Superfícies neutras, acento roxo usado com parcimônia.
2. **Consultoria, não produto**: linguagem visual próxima de um relatório bem diagramado, não de um SaaS.
3. **Coerência sistêmica**: qualquer mudança visual no app deve ser refletida no design system (style.css). Sem one-offs.
4. **Hierarquia legível**: navegação deve orientar sem dominar. Conteúdo sempre é o protagonista.
5. **Modernidade funcional**: moderno porque é útil e bem executado, não porque tem efeitos.

## Accessibility & Inclusion

WCAG AA como alvo. Contraste mínimo 4.5:1 para texto. Sem dependência exclusiva de cor para estados.
