Witly Grimório — como funciona

Uma plataforma na Cloudflare que entrega templates de análise ao agente que a pessoa já usa. O MCP é inteligência, não compute: o Python roda na máquina do consultor. Atualizado em 2026-09-07 · Fase 1: US1 em produção com login Google.

O fluxo, ponta a ponta

máquina da pessoa este projeto Delfos (não muda) Google
O que acontece
  1. A pessoa cola a URL do MCP no agente; o navegador abre o login Google; sem token digitado.
  2. O agente chama listar_templates e obter_template: recebe manifesto, tarefas de contexto, queries, documento, guia e contextos gerais como texto, e uma URL assinada do zip.
  3. Executa as tarefas de contexto com o consultor (lançamento, tipo de funil, temperatura, metas…) e monta o config.json.
  4. montar_query devolve o SQL preenchido; roda no Delfos; salva dump.csv local.
  5. python gerar.py → 4 camadas + numeros.json + relatorio.html (o mesmo relatório do app, offline).
  6. Dali em diante o documento é da pessoa.
Princípios que não mudam
  • Número nasce no calc.py; o modelo escreve prosa.
  • Dado pessoal nunca sobe; linha crua nunca; agregado pode.
  • Contexto é por análise; os gerais são poucos e curados.
  • Template autossuficiente e versionado; o MCP serve só o publicado.
  • Uma plataforma, um login (Google).
  • Spec-driven + testes unitários por tarefa.

Requisitos para estar funcionando

Na Cloudflare (conta Witly)
  • Worker publicado (npm run deploy) no workers.dev.
  • D1 witly-templates criado, migrations aplicadas, seed rodado (npm run seed:remote).
  • KV OAUTH_KV criado; ids no wrangler.jsonc.
  • Secrets: GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, COOKIE_ENCRYPTION_KEY.
  • Vars: ALLOWED_DOMAIN=witly.digital, EDITOR_SEED (primeiro editor), PUBLIC_URL (a URL do Worker).
No Google Cloud
  • Um OAuth client (tipo Web) com redirect https://<worker>/callback.
  • Tela de consentimento com escopos email profile.
Na máquina de quem usa
  • Um agente com MCP remoto (Claude Code, Claude.ai, Codex, Cursor).
  • Conta Google do domínio.
  • Python 3 e curl. Acesso ao Delfos para o dado.
