# Uma palavra, um sentido: budget = valor configurado; investimento = valor realizado; desligar (não pausar/cortar); criativo = nome do anúncio; lead ≠ MQL ≠ resposta; checkout = iniciado

Use sempre a mesma palavra para o mesmo conceito. Termo de mídia fica em inglês quando é o jargão (adset, ROAS, CBO). Termo novo recorrente: defina na primeira vez e não varie.
