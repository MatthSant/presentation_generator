# O título "quase específico" engana mais que o grandioso: parece objetivo sem dado; apague as variáveis concretas e, se ainda vale para qualquer base, falta o número

"O [item] típico não existe" serve para criativos, produtos, clientes ou lojas: é genérico. Um título específico não passa nesse teste porque as variáveis abstratas são o número.
