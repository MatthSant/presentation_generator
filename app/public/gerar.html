Nova análise

Suba o dump de pesquisa (uma linha por combinação de dimensões × lançamento × canal), confirme os critérios e gere a análise. Os números são calculados no servidor; o arquivo bruto não é guardado.

IdentificaçãoO slug da análise é criado automaticamente a partir do cliente.
Nenhum cliente cadastrado — cadastre um cliente primeiro. O slug é criado automaticamente.
Arquivo de dados (CSV)Dump de pesquisa — as colunas são lidas no servidor para sugerir os critérios.

CritériosDimensões que viram páginas no relatório.

Marque as dimensões a analisar. Em cada uma, arraste os grupos para reordenar, clique em 2 ou mais e use Juntar para fundir variantes, e clique no nome para renomear. O número mostra a representatividade de cada grupo.
