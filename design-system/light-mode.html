Design System — Light Mode

Versão light do design system para apresentações Reveal.js. Mesma estrutura de classes do modo escuro — apenas os tokens e valores de superfície mudam. Use shell-light.html como base e backgrounds da pasta backgrounds/light/.

Tokens — Dark vs Light

As cores de acento (purple, green, amber, orange, red) ficaram ligeiramente mais escuras para manter contraste WCAG AA sobre fundo branco. Superfícies e bordas foram invertidas.

Mdef Blocks

Métrica
LTV — Lifetime Value
Soma de todas as receitas geradas por um cliente desde a primeira compra até a data de corte da análise.
Fórmula
LTV = Σ(valor das compras) × (1 − taxa de devolução)

Taxa de Retorno
Percentual de clientes que realizaram ao menos uma compra adicional dentro de 60 dias após a primeira.

CSS Overrides — resumo completo

Diferenças entre shell.html (dark) e shell-light.html (light). Classes HTML idênticas — apenas os valores mudam.
/* 1. Tokens de raiz */
:root {
  --bg:        #F9FAFB;   /* era #0C0C0C */
  --border:    #E5E7EB;   /* era #272727 */
  --gray:      #4B5563;   /* era #B8BEC8 */
  --gray2:     #6B7280;   /* era #9CA3AF */
  --purple:    #7C3AED;   /* era #8B5CF6 — mais escuro p/ contraste AA */
  --purple-d:  #EDE9FE;   /* era #5B21B6 — flip para tint claro */
  --green:     #059669;   /* era #10B981 */
  --amber:     #D97706;   /* era #F59E0B */
  --orange:    #EA580C;   /* era #F97316 */
  --red:       #DC2626;   /* era #EF4444 */
}
